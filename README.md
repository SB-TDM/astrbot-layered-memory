# user_memory — 给 AstrBot 加一层「记得人」的记忆

AstrBot 内置只有「最近若干条对话」，换个会话就忘了你是谁，也没有任何长期偏好记录。
这个插件给**每个 QQ 号**维护一份小档案：自动从聊天里抽取稳定事实，去重、定期压缩，并在下一轮对话时注入提示词。

## 它做什么

```
每条消息进模型前 → 把该用户的档案 + 好感度拼进 system prompt
回复生成后      → 后台调一次模型，从这轮对话里抽取稳定事实，写回档案
```

注入的内容长这样：

```
关于正在跟你说话的这个人（你以前记下来的，别当新信息问）：
- QQ 123456789，昵称 某个人
- 身份：上班族
- 技术栈：pywebview
- 偏好：喜欢猫
自然地用这些信息就行，别复述，也别一条条念出来。

你对这个人的好感度是 62/100。按人设里的分档决定亲近程度，
别把数字念出来，也别问对方好感度多少。
```

## 特性

| 特性 | 说明 |
|---|---|
| **自动抽取** | 从对话里提炼身份、职业、长期偏好、雷点，不记一次性情绪 |
| **不记称呼** | 「爸」「哥」这类称呼随时会改，记了会和人设打架 |
| **写时去重** | 归一化后相似度 ≥ 0.85 判重，保留较新的措辞 |
| **定期压缩** | 超 15 条自动压缩到 10 条；每周一 04:30 全量压一遍 |
| **好感度注入** | 从 `astrbot_plugin_self_learning` 的库里读取，按 QQ 号取最高值 |
| **权限隔离** | 查看他人档案需要管理员 |

## 安装

1. 把 `plugins/user_memory/` 整个目录复制到 `AstrBot/data/plugins/`。
2. 重启 AstrBot。
3. 在面板的插件配置页调整参数（见下）。

依赖：AstrBot >= 4.29。好感度功能需要另外安装 `astrbot_plugin_self_learning`，没装时插件会自动跳过好感度注入。

## 配置项

配置文件：`AstrBot/data/config/user_memory_config.json`（首次保存后生成，或从下表的默认值手写一份）。

| 配置项 | 默认 | 说明 |
|---|---|---|
| `enable` | `true` | 总开关，关掉后不注入、不抽取、不压缩 |
| `inject_profile` | `true` | 注入档案 |
| `inject_affection` | `true` | 注入好感度 |
| `extract_enabled` | `true` | 自动抽取事实 |
| `min_interval_seconds` | `300` | 同一个号两次抽取的最短间隔 |
| `min_message_length` | `4` | 消息短于这个字数不抽取 |
| `max_facts` | `30` | 每人最多保留条数 |
| `similarity_threshold` | `0.85` | 去重相似度阈值 |
| `compact_enabled` | `true` | 启用压缩 |
| `compact_threshold` | `15` | 超过多少条触发压缩 |
| `compact_target` | `10` | 压缩后保留多少条 |
| `weekly_compact` | `true` | 每周一 04:30 全量压缩 |

常用组合：

| 想达到什么 | 怎么调 |
|---|---|
| 完全静音 | `enable = false` |
| 只记不注入 | `inject_profile`、`inject_affection` 都关 |
| 省调用 | `min_interval_seconds` 调到 600，`min_message_length` 调到 8 |
| 记性更细 | `min_interval_seconds` 调到 120 |
| 不让它自己精简 | `compact_enabled = false`（到 30 条丢最旧的） |

## 命令

| 命令 | 作用 |
|---|---|
| `/记忆` | 看自己的档案 |
| `/记忆 <QQ号>` | 看别人的档案（仅管理员） |
| `/忘记` | 清空自己的档案 |
| `/压缩档案` | 立刻压缩自己的档案 |

## 怎么判断"值得记"

抽取提示词里划了两条线：

**记**：职业、身份、长期爱好、常用工具或技术栈、明确表达过的偏好和雷点、长期在做的事。

**不记**：称呼和叫法、一次性的情绪、当天吃了什么、临时安排、礼貌性寒暄、机器人自己说过的话。

"不记称呼"是刻意的——称呼属于人设，记忆负责事实。两者混在一起会互相覆盖，出现「人设说叫爸、记忆说他不喜欢被叫爸」这种分裂。

## 数据结构

`data/plugins/user_memory/profiles.json`：

```json
{
  "123456789": {
    "name": "某个人",
    "facts": ["身份：上班族", "偏好：喜欢猫"],
    "updated": "2026-10-27 19:26:05"
  }
}
```

明文 JSON，删掉即重置。

## 成本

每次抽取是一次额外的模型调用，所以调了冷却时间（默认 5 分钟一个号一次）。按 DeepSeek 的价格，正常聊天一天几毛钱。

档案本身很小——每人最多 30 条，注入时占几百 token。
